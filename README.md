# 🧠 Anthra's AI Brain (Chrome Extension Mod)

**Author:** anthrakys  
**Version:** 1.2.0  
**Target:** [rngidle.fun](https://rngidle.fun)

A high-performance decision-making Chrome Extension (Manifest V3) for **rngidle.fun** that analyzes rolls in real time and computes **exact mathematical profitability**, **net profit (EP)**, and **win / loss probabilities** across all 10 shop items.


---

## 🚀 Installation & Update in Chrome / Brave / Edge

1. Open your browser and navigate to `chrome://extensions/`.
2. Enable **Developer mode** (toggle in the top-right corner).
3. If previously loaded: click the **Reload (🔄)** icon on the **Anthra's AI Brain** card.
   If installing for the first time: click **Load unpacked** and select `c:\Users\anthr\Desktop\RNGidle MODS`.
4. Open [https://rngidle.fun/](https://rngidle.fun/) and hard-refresh (`Ctrl + F5`).
5. The overlay will seamlessly appear on the right side of the screen.

### 🦊 Mozilla Firefox

1. Download and unzip **`Anthras-AI-Brain-v1.2.0.zip`** (or clone the repository).
2. Open Firefox and navigate to:
   ```text
   about:debugging#/runtime/this-firefox
3. Click Load Temporary Add-on... (Charger un module temporaire...).
4. Select the manifest.json file inside the folder.
5. Open https://rngidle.fun/
